# Review checklist

## Correctness

- [ ] The change matches the stated goal
- [ ] Edge cases are considered
- [ ] Error handling is deliberate

## Scope

- [ ] No unrelated changes
- [ ] No accidental dependency expansion
- [ ] No hidden configuration changes

## Security

- [ ] No credentials in source, logs, examples, or screenshots
- [ ] Permissions are no broader than required
- [ ] External actions or dependencies are reviewed

## Verification

- [ ] Tests match the risk
- [ ] Important claims have evidence
- [ ] Generated output is reproducible where practical

## Operations

- [ ] Failure is detectable
- [ ] Recovery or rollback is understood
- [ ] Consequential actions require explicit authority
